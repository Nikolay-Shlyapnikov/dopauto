# Пробная секция — результаты (2026-11-03)

Проверено в предпросмотре редактора кастомных секций Яндекс KIT (магазин ДопАвто), секция не сохранялась и не публиковалась.

| Тест | Результат | Вывод для лендинга |
|---|---|---|
| A. `ya-kit-value-controller` + `ya-kit-clickable-area` | работает | основной способ для переключателя материалов, точек «+», отзывов |
| B. `<input type="radio">` + `:checked` | работает, но атрибут `checked` при рендере теряется (изначально ничего не выбрано) | запасной вариант; использовать A |
| C. Стрелки по кругу через `add`/`subtract`/`if` | работает, переход 1 → 3 по кругу | отзывы и баннеры со стрелками |
| D. `ya-kit-carousel` | стрелки работают; на телефоне 1 колонка, без стрелок, нативная горизонтальная прокрутка | свайп есть; проверить на реальном телефоне |
| E. `ya-kit-intersection-controller` + `ya-kit-transition` | рендерится; саму анимацию в предпросмотре визуально не подтвердили | проверить на опубликованной странице |
| F. Шрифты | Manrope — недоступен; Inter — доступен (похоже, шрифт темы) | Manrope нужно включить в теме (Тема → Типографика) или заменить; AKONY — только картинками/SVG |

Ограничения из документации скилла: `@font-face` с внешним `url()` ломает CSS всей страницы, `<script>`/`<style>` вырезаются, `//` в CSS запрещён.
