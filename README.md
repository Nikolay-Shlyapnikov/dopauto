# Лендинг ДопАвто на Яндекс KIT

Лендинг собран из **кастомных секций Яндекс KIT**. Каждая секция — это три файла (HTML-шаблон, CSS, JSON-схема настроек), которые вставляются в редакторе сайта KIT. JavaScript в секциях KIT запрещён, поэтому вся интерактивность (точки «+», переключатели, карусели, анимации при прокрутке) сделана на компонентах `ya-kit-*` и CSS.

Контент (тексты, фото, видео, ссылки) не зашит в код: он заполняется в форме настроек каждой секции в KIT. В коде лежат только разметка, стили и значения по умолчанию.

- Магазин: kit26729 (`dopauto.shop`), страница лендинга — `/landing` (скрытая).
- Макет: [Figma](https://www.figma.com/design/4f5TTgSiIiHOSrVuT9k6vY/Untitled) — фреймы «1440 ПК (без анимации)» и «Mobile».
- Исходные материалы заказчика: папка `МАТЕРИАЛЫ` (ТЗ, `ПК.pdf`, `Mobile.pdf`, фото, видео, логотипы).

## Структура

```
src/
  shared/base.css          общие стили: переменные, шрифт, заголовки, кнопки, «+», слова AKONY
  sections/<секция>/
    template.html          шаблон (Handlebars + теги ya-kit-*) с макросами сборки
    styles.css             стили секции
    schema.json            JSON-схема формы настроек
tools/
  build-sections.mjs       сборка src → dist
  upscale.mjs              увеличение картинок до 600 px для формы KIT
  split-word.mjs           разбивка слова AKONY на две строки для телефона
assets/
  akony/                   слова AKONY в кривых (SVG), см. assets/akony/README.md
  icons/                   иконки преимуществ hero
  upscaled/                картинки, увеличенные для загрузки в KIT
docs/figma-notes.md        заметки по макету
sections/_probe/           пробная секция, на которой проверялись возможности KIT
dist/                      результат сборки (в git не хранится)
```

## Установка и сборка

Нужен Node.js 18+.

```bash
npm install
```

```bash
npm run build
```

Собрать только нужные секции:

```bash
node tools/build-sections.mjs text banner
```

Сборка кладёт в `dist/sections/<секция>/` три готовых файла: `template.html`, `styles.css`, `schema.json`. Именно их вставляют в KIT, файлы из `src/` вставлять нельзя.

Что делает сборка:

- **CSS:** в начало `styles.css` каждой секции дописывается `src/shared/base.css`. Поэтому после правки общих стилей нужно обновить `styles.css` во **всех** секциях.
- **Шаблон, `@@word:<файл>@@`:** вставляет SVG-слово из `assets/akony/<файл>.svg`, цвет берётся из CSS (`currentColor`).
- **Шаблон, `@@repeat N@@ … @@end@@`:** повторяет блок N раз, `@@i@@` → 1…N.
- **Шаблон, `@@repeat A..B@@ … @@end@@`:** повторяет блок для номеров A…B.
- **Схема, `"@@repeat": [{ "count", "from", "properties", "defaults" }]`:** разворачивается в пронумерованные поля (`spot1Title`, `spot2Title`, …) со своими значениями по умолчанию. `from` сдвигает нумерацию, `@@n@@` — номер внутри группы (для подписей полей).

Повторы нужны потому, что форма KIT не умеет редактировать массивы (`modules`), поэтому вместо списка — пронумерованные поля.

### Проверка (линтер)

Линтер — скилл `kit-custom-sections` для Claude Code. Он проверяет теги, хелперы, схему и CSS без отправки в KIT:

```bash
python ~/.claude/skills/kit-custom-sections/scripts/section.py lint dist/sections/text
```

Предупреждения `[G6] хардкод цвета` ожидаемы: цвета фирменные, из макета. Ошибок быть не должно.

## Как вставить секцию в KIT

1. Войти в кабинет KIT → **Редактор сайта**.
2. Новая секция: **Секции → Добавить секцию → Кастомные секции → Создать секцию** и вставить три файла из `dist/sections/<секция>/` в соответствующие поля.
3. Обновление существующей секции: открыть её шаблон в редакторе кода и заменить файлы. Шаблон один на все места, где секция стоит на странице.
4. Заполнить форму настроек секции: тексты, фото, видео, ссылки.
5. **Опубликовать.**

Что важно знать про KIT:

- **Черновик хранится только в браузере**, где его правили. В другом браузере (или у другого человека) правки видны только после публикации.
- **«Опубликовать» публикует весь сайт**, а не одну страницу. Перед публикацией проверить, что в черновике нет чужих правок на других страницах. Магазин рабочий, с реальными заказами.
- **Скрытая страница** снаружи отдаёт «Такой страницы нет», посетители её не видят.
- **Превью иногда показывает старую версию** секции из кеша. Если правка «не работает», сначала обновить превью или страницу.
- **После смены схемы** (новые или переименованные поля) значения этих полей в уже вставленных секциях нужно заполнить заново.

### Настройки текстовых блоков (`text`)

Все четыре блока — одна секция с разными настройками. Значения в пикселях даны для ширины 1440, на других ширинах масштабируются.

| Блок | Абзацы под заголовком | Сдвиг слева | Отступ 2-й строки | Ширина абзацев | Слово на фоне |
|---|---|---|---|---|---|
| 1-й | нет | — | 245 | 312 | Нет |
| 2-й | да | 244 | 561 | 257 | Нет |
| 3-й | нет | — | 424 | 340 | ДЕТАЛИ |
| 4-й | да | 370 | 271 | 297 | МАТЕРИАЛ |

«Заголовок на телефоне» — свой вариант заголовка для мобильной версии: переносы строк и пробелы в начале строк сохраняются, так повторяется «лесенка» из мобильного макета.

### Особенности других секций

- **materials:** точки 1–5 — первый баннер (ТЭП), 6–8 — второй (Резина). Точки заполнять подряд, без пропусков: стрелки листают их по номерам.
- **hotspots:** то же правило — точки заполнять подряд.
- **Координаты точек «+»** — проценты от ширины и высоты картинки, число с точкой (`20.4`, не `20,4`).
- **wholesale:** настройка «Показывать» (везде / только ПК / только телефон). На ПК опт стоит перед отзывами, на телефоне — после, поэтому секция ставится дважды.
- **banner:** у заголовка, подзаголовка и кнопок есть варианты «на телефоне» и «только на телефоне».
- **articles:** статьи подтягиваются из блога магазина (Редактор сайта → Блог), вручную не заполняются.

## Картинки и видео

### Откуда брать

| Что | Где взять |
|---|---|
| Фото, видео, логотипы | папка заказчика `МАТЕРИАЛЫ` (Баннеры, Каталог, Лого/Цветные, Опт, УТП, Аватары, Видео) |
| Чего нет в материалах (иконки hero, недостающие фото) | Figma: выделить слой → Export → PNG 3x |
| Крупные слова AKONY | Figma: слой слова → Copy as SVG → `assets/akony/` (подробно в `assets/akony/README.md`) |
| Статьи | блог в кабинете KIT |

Логотипы нужны только **цветные**: серый цвет делается стилями, цвет появляется при наведении.

### Куда класть

- Фото, видео и логотипы **не кладутся в код**. Их загружают через форму настроек секции в KIT (поля «фото», «видео», «иконка» и т. п.).
- В репозитории хранятся только слова AKONY (`assets/akony/`), иконки hero (`assets/icons/`) и увеличенные копии картинок (`assets/upscaled/`) — для удобства загрузки.

### Если KIT не принимает картинку меньше 500 px

Форма KIT отклоняет изображения меньше 500 px. Увеличить копии (Lanczos, пропорции сохраняются, бо́льшая сторона становится 600 px; оригиналы не меняются, достаточно большие файлы пропускаются):

```bash
npm run upscale -- "путь/к/МАТЕРИАЛЫ/Каталог" assets/upscaled/Каталог
```

Третьим аргументом можно задать другой размер, например `1170` для фона на всю ширину телефона. Новых деталей увеличение не добавляет, но на сайте картинки показываются в том же или меньшем размере, так что разница незаметна.

### Слово AKONY для телефона в две строки

```bash
node tools/split-word.mjs assets/akony/material.svg assets/akony/material-mobile.svg 6 104.5
```

Аргументы: исходный SVG, результат, сколько букв в первой строке, шаг строки. После этого — `npm run build`.

## Шрифт

Лендинг берёт шрифт из темы сайта (`--ys-font-family`): **Редактор сайта → Тема → Шрифт**. Сейчас выбран Inter. Свой шрифт (например, Manrope) загружается в теме файлами, после этого лендинг переключится сам. Шрифт темы общий для всего магазина. Подключить шрифт только для лендинга из CSS секции нельзя.

## Ограничения KIT, которые учтены в коде

- В HTML вырезаются `<script>` и `<style>`; JavaScript в секциях нет.
- В CSS запрещены `@font-face`, `//` (даже внутри `url()`), `:global(` и символ `<`. CSS автоматически ограничивается секцией.
- Поля типа `number` в форме ломаются (ползунок превращает значение в NaN) — все числа в схемах сделаны текстовыми полями.
- Форма игнорирует `enumNames` и добавляет к каждому списку вариант «Как в теме»; шаблоны это учитывают.
- `ya-kit-section-layout` ограничивает ширину 1400 px — не используется.
- Слишком большой шаблон (~50 КБ) редактор KIT не открывает; держать `template.html` компактным (сейчас максимум ~27 КБ).
- `ya-kit-image` внутри — блок с двумя `<img>` (размытая заглушка и сама картинка); позиционирование картинок внутри него не переопределять.
