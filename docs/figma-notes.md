## «Варианты для анимации» — состав

- **Слова AKONY** (компоненты с вариантами «Показан» / «Скрыт»; внутри живой текстовый слой, не кривые):
  Качество (22-3034, 1097×212), Детали, Материал, Сотрудничество, Отзывы.
- «ДОПАВТО» — не анимируется, лежит фоном в «Katalog vse — прокрутка» (4 состояния прокрутки каталога).
- 9 компонентов «… — появление при наведении» — состояния точек «+»:
  баннер с машиной (4 состояния), ТЭП (5), Резина (4). Фото для правой панели — в `МАТЕРИАЛЫ/Баннеры/…` (без текста; подписи берём из Figma).
- «Переключение баннеров» — 2 состояния ТЭП / Резина.
- «Rewi» — 10 состояний блока отзывов.
- «Марка / …» — 18 логотипов (ч/б → цвет при наведении).
- «FAQ / Оригинальные коврики» — раскрытый вопрос.
- «plus», «Content 2», «Content 1/3», «Default» — кнопка «+» и состояния баннера.
